

Project: Restaurant & Food Delivery SQL Dataset
--------------------------------------------------

This project demonstrates SQL operations on a restaurant ordering and delivery system.
It covers schema creation, sample data insertion, and 20 categorized SQL queries ranging 
from basic to advanced window functions.

DATABASE STRUCTURE:
-----------------------
Tables created:
1. Customers
2. Restaurants
3. Dishes
4. Orders
5. Deliveries
6. Reviews

Each table includes realistic sample data covering customers, restaurants, dishes, orders,
delivery details, and reviews.

📊 QUERY CATEGORIES & EXAMPLES:
-------------------------------

🔹 **Basic Queries**
1. List all dishes with their restaurant names and prices.
2. Average rating of restaurants in New York.

🔹 **Intermediate Queries**
3. Total revenue per restaurant (with and without subqueries).
4. Customers who ordered more than once.

🔹 **Advanced Window Functions**
5. Rank restaurants based on rating.
6. Cumulative revenue per restaurant.
7. Top 2 most ordered dishes per city.
8. Rank delivery persons by average delivery time.

🔹 **Aggregations and Grouping**
9. Order count per city.
10. Average order value by cuisine.
11. Reviews with rating below 4.
12. Orders placed after a specific date.

🔹 **Joins**
13. Orders with customer and restaurant names.
14. Dishes ordered by each customer.

🔹 **Subqueries**
15. Customer who gave the lowest rating.
16. Most expensive dish per cuisine.

🔹 **Analytical Queries**
17. Fastest delivery person by average time.
18. Avg delivery time by specific delivery person.
19. Rank customer reviews by review date.

🔹 **Advanced Window Functions**
20. Running total of revenue by each customer.

TECHNOLOGIES USED:

- SQL Window Functions
- Joins, Aggregations, Subqueries
- GROUP BY, HAVING, ORDER BY
- Functions: RANK(), ROW_NUMBER(), SUM() OVER(), AVG()

NOTE:
---------
- Data is minimal but enough to demonstrate logic and edge cases.
- Queries are structured and commented for clarity.
- Window functions used where aggregation or ranking is meaningful.
